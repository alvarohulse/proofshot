# How to configure ProofShot

ProofShot works out of the box with sensible defaults. For projects with non-standard setups, you can customize behavior with a config file or command-line flags.

<Steps>
### Create a config file

Create `proofshot.config.json` in your project root:

```json filename="proofshot.config.json"
{
  "devServer": {
    "port": 5173,
    "startupTimeout": 60000
  },
  "output": "./proofshot-artifacts",
  "viewport": {
    "width": 1440,
    "height": 900
  }
}
```

ProofShot searches for this file starting from your current directory upward to the filesystem root — so it works in monorepos when the config lives at the repo root.

### Override with CLI flags

Command-line flags take precedence over the config file:

```sh
proofshot start --port 8080 --output ./my-artifacts --headed
```
</Steps>

## All configuration options

Every option, type, and default lives in the [configuration reference](/docs/reference/configuration) — including the `browser`, `environment`, and `logs` blocks for multi-process apps, tmux panes, and file tails.

<Callout type="info">
You don't need a config file for most projects. The defaults work for standard setups, and CLI flags cover one-off overrides.
</Callout>
